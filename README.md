# 상품 이미지 자동 리사이징 도구

누끼 이미지를 각 채널사별 규격에 맞게 자동으로 리사이징하는 Python 스크립트입니다.

## 기능

- ✨ 누끼 이미지의 흰색 배경 자동 제거
- 📏 채널사별 이미지 규격에 맞게 자동 리사이징
- 🎯 예시 결과물을 참고하여 동일한 레이아웃 적용
- 📁 폴더 구조 및 파일명 자동 관리

## 지원하는 채널사

- **W컨셉**: 960x1280
- **자사몰,29CM,HAGO,EQL**: 1200x1200, 1200x1500
- **코오롱몰**: 1500x2250

## 설치

```bash
pip install Pillow numpy
```

## 사용 방법

### 폴더 구조

```
프로젝트 폴더/
├── resize_images.py        # 리사이징 스크립트
├── 누끼 이미지/            # 리사이징할 원본 이미지
│   └── [상품명]/
│       └── [색상명]/
│           └── *.jpg
├── 예시 결과물/            # 각 채널사의 규격 예시
│   ├── W컨셉/
│   ├── 자사몰,29CM,HAGO,EQL/
│   └── 코오롱몰/
└── ★엠디 작업용/          # 리사이징 결과 저장 폴더
    └── 썸네일/
        ├── W컨셉/
        ├── 자사몰,29CM,HAGO,EQL/
        └── 코오롱몰/
```

### 실행

```bash
python resize_images.py
```

## 동작 원리

1. **배경 제거**: 누끼 이미지의 흰색 배경을 투명으로 변환
2. **상품 추출**: 투명 영역을 제거하여 상품 부분만 남김
3. **규격 맞춤**: 예시 이미지의 규격에 맞게 리사이징
4. **중앙 배치**: 상품을 새로운 캔버스의 중앙에 배치
5. **파일 저장**: 예시 결과물의 파일명 패턴에 맞게 저장

## 파일명 생성 규칙

예시의 파일명 패턴을 분석하여 색상명만 변경:

- `CHOCO-BROWN-1.jpg` → `AGED-BLUE-1.jpg`
- `CHB-1.jpg` → `AB-1.jpg` (색상 약자)
- `썸네일_2.jpg` → `썸네일_2.jpg` (썸네일은 그대로 유지)

## 색상 약자 생성

색상명의 첫 글자를 조합하여 약자 생성:
- AGED BLUE → AB
- CHOCO BROWN → CHB
- BLACK → B

## 예시

```
누끼 이미지/BOAT MINI/AGED BLUE/420.jpg
                                    ↓
                            (배경 제거 및 리사이징)
                                    ↓
★엠디 작업용/썸네일/W컨셉/BAG/BOAT MINI/AGED BLUE/AB-1.jpg
★엠디 작업용/썸네일/자사몰,29CM,HAGO,EQL/BAG/BOAT MINI/AGED BLUE/AB-1.jpg
★엠디 작업용/썸네일/코오롱몰/BAG/BOAT MINI/AGED BLUE/AB-1.jpg
```

## 주의사항

- 예시 결과물 폴더의 이미지들이 올바른 규격이어야 합니다
- 누끼 이미지의 배경이 흰색이어야 합니다 (RGB 240 이상)
- 충분한 디스크 공간이 필요합니다
